# ESTIMATE

Analysis code for the ESTIMATE study, which tests whether alternative survey methods can validly estimate childhood vaccination coverage in conflict-affected and inaccessible populations.

This repository is a placeholder release (v0.0.1) created to reserve a citable software DOI. The analysis code will be deposited here in full at a later date.
